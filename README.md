# Rooted 🌱

Pop Culture Through a Biblical Lens

## About

Rooted helps teens explore trending pop culture topics through a Christian perspective. Each article highlights biblical values and lessons that can be learned from current celebrity news and social trends.

## Features

- 📱 Mobile-first responsive design
- 🎨 Clean, modern, teen-friendly interface
- ✨ Biblical perspective on pop culture topics
- 🏷️ Category filtering
- 📖 Bible verses with each article
- 💜 Gradient design with purple/pink theme

## Tech Stack

- **Next.js 14+** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Vercel** - Deployment platform

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
