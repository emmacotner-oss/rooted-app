# 🚀 START HERE - Deploy Your App in 10 Minutes!

## Your app is ready! Follow these 3 simple steps:

---

## Step 1: Create GitHub Repository (2 min)

1. Open: **https://github.com/new**
2. Fill in:
   - Repository name: **rooted-app**
   - Description: **Pop culture through a biblical lens**
   - Select: **Public**
   - **DON'T** check any boxes below
3. Click: **"Create repository"**

---

## Step 2: Push Your Code (1 min)

Open your terminal in the `rooted-app` folder and run:

```bash
git remote add origin https://github.com/emmacotner-oss/rooted-app.git
git branch -M main
git push -u origin main
```

If it asks for authentication, use your GitHub credentials or Personal Access Token.

---

## Step 3: Deploy to Vercel (5 min)

1. Open: **https://vercel.com**
2. Click: **"Add New Project"**
3. Click: **"Import"** next to your `rooted-app` repository
4. Click: **"Deploy"** (keep all default settings)
5. Wait 2-3 minutes ⏱️

---

## 🎉 That's it!

Vercel will give you a live URL like: **https://rooted-app.vercel.app**

Your app is now:
- ✅ Live on the internet
- ✅ Automatically deploys when you push to GitHub
- ✅ Mobile-friendly
- ✅ Fast and optimized

---
